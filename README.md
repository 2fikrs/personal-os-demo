# PERSONAL OS — iPhone UI test

Démo publique **strictement fictive** de l'interface PERSONAL OS V1.10.

## Objectif
Tester dans Safari sur iPhone :
- le pull-to-refresh ;
- le contrôle discret `Mis à jour à HH:MM ↻` ;
- le détail progressif d'une tâche par bottom sheet ;
- la fermeture par swipe vers le bas ;
- le scroll, la fluidité et le dark mode système.

## Sécurité
Ce dépôt ne contient aucune donnée personnelle réelle ni accès direct à une source.

Le refresh est simulé localement et les détails de tâches sont entièrement fictifs.

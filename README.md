# PERSONAL OS — iPhone UI test

Démo publique **strictement fictive** de l'interface PERSONAL OS V1.9.

## Objectif
Tester dans Safari sur iPhone :
- le pull-to-refresh ;
- le contrôle discret `Mis à jour à HH:MM ↻` ;
- le scroll, la fluidité et le dark mode système.

## Sécurité
Ce dépôt ne contient :
- aucune donnée Gmail, Calendar ou Asana ;
- aucun secret, token ou identifiant personnel ;
- aucun accès direct à une source réelle.

Le refresh de cette démo est simulé localement pendant ~0,7 s afin de tester uniquement l'interaction.
